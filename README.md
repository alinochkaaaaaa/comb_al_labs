задача 2:
Условие задачи.
Нам дан связный неориентированный граф. Нужно определить, является ли он двудольным.

Двудольный граф — это граф, вершины которого можно разделить на два множества (доли) так, что каждое ребро соединяет вершины из разных долей. Внутри одной доли нет рёбер.

Метод решения: Поиск в глубину (DFS).

Входные данные:
Первая строка: число N (количество вершин, 1 ≤ N ≤ ?)
Далее матрица смежности N×N

Выходные данные:

Если граф НЕ двудольный: вывести "N"

Если граф двудольный:
Первая строка: "Y"
Вторая строка: вершины первой доли (по возрастанию)
Третья строка: вершины второй доли (по возрастанию)
Первой печатается доля, содержащая вершину с минимальным номером

Пример

Ввод:
4
0 1 1 0
1 0 1 0
1 1 0 1
0 0 1 0
Вывод:
N

Алгоритм решения

Идея: При обходе графа раскрашиваем вершины в два цвета (0 и 1)
Если смежные вершины получают одинаковый цвет — граф не двудольный
Иначе после обхода собираем вершины по цветам
Определяем, какая доля содержит минимальную вершину (вершину 1)
